Colour themes

The same Receipts components in six palettes. Each theme is one set of tokens; the receipt paper stays white in every theme so shared images look like a real receipt. Contrast is checked live against WCAG AA (4.5:1 for text).

To adopt a theme, copy its tokens (button under each card) into :root. In demo.html, a few colours are still hard-coded (card white #fff, labels on dark cards #A9A69D, the green net amount) and would need switching to these tokens first.
